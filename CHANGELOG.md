# Changelog

## [0.1.0] — 2026-09-24

### Added

- Initial public release of the Climate Infrastructure Resilience Simulator
- Core modules: units, simulation time, synthetic weather, building thermal model, electrical network with DC power flow, transformer thermal/aging, cascade engine, resilience metrics
- CLI (`resilience-sim`) with `run`, `compare`, `validate-config`, `version`
- Catch2 unit and integration tests
- CMake build with FetchContent dependencies
- Documentation of models, assumptions, and limitations
- Author: Nabil Khondaker
