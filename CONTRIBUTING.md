# Contributing

Contributions that improve numerical correctness, test coverage, documentation clarity, or modular extensions (water network, storage, optimization) are welcome.

1. Open an issue describing the proposed change.
2. Keep commits focused.
3. Ensure `cmake --build` and `ctest` succeed.
4. Follow existing code style (clang-format configuration provided).
5. Do not add Python runtime dependencies for core functionality.

By contributing you agree that your contributions are licensed under the MIT License.
